# Session Wrap - Usage TUI Finalization

## Summary

This session finalized the Codex usage observer into a production-ready lightweight TUI and stabilized related repository entrypoints.

## Completed Work

- Fixed Python entrypoint consistency across repository scripts by injecting `PYTHONPATH="$ROOT"` into `scripts/*.sh` wrappers that call `tools.codex_assets`.
- Unified `curate-memory` onto the shared `tools.codex_assets` CLI entrypoint instead of executing a Python file path directly.
- Implemented the first usable local usage observer:
  - `scripts/usage-report.sh`
  - `scripts/usage-tail.sh`
  - `tools/codex_assets/usage_dashboard.py`
- Added real-time usage data collection from:
  - `~/.codex/sessions/**/*.jsonl` token events
  - `~/.codex/state_5.sqlite` thread and goal state
- Evolved the usage observer into a lightweight interactive TUI:
  - views: `summary`, `threads`, `trends`, `auto`
  - interactive mode: `--interactive`
  - keys: `1/2/3/a/r/p/+/-/j/k/h/q`
- Compressed the default `summary` view into a single-screen decision dashboard.
- Added `Trend 30m` sparkline plus `5m/15m/30m` rate windows.
- Added `Top Models`, `Top Repos`, and recent hot-path aggregates.
- Added structured risk evaluation:
  - `status`
  - `advisories`
  - `severity`
  - `code`
  - `summary`
  - `action`
  - `evidence`
- Added `threads` view sort switching:
  - `updated`
  - `tokens`
  - `model`
  - `repo`
- Fixed SSH/remote interactive key handling by reading keys from `/dev/tty` instead of relying on `sys.stdin`.
- Wrote and synchronized usage and token-efficiency guidance into repository docs and AGENTS rules.
