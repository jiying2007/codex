# 技能发现、来源与同名处理

`manifests/skills.json`负责受管技能版本和安装；`manifests/skill_discovery.json`只登记本机允许查询的团队技能源及名称白名单，不安装、复制、提升或执行外部技能。

团队库根由`EMBEDDED_KNOWLEDGE_HOME`或声明的默认根解析。仅读取白名单的`<name>/SKILL.md`，不递归扫描业务工作区、认证或会话目录；越过源根的链接与名称不符均失败。实际项目局部skill仍由项目规则显式加载，不因为父目录存在catalog就假定递归发现。

本CLI中，同名受管条目优先；外部同名列表作为shadowed提示，保留两份正文并按项目规则选择，不自动合并或覆盖。被禁用/待审的受管条目也不能借同名外部项绕过治理。输出source_id、load_path和正文hash；active/deferred只说明发现/加载方式，不授予修改或设备操作权限。

外部目录不可用和检索零命中分别报告；零命中不是不存在。已有能力应先修路由或增加明确触发，不以创建近义skill解决检索缺口。短摘要保留预算，详细正文仅按选中路径读取。

验收包括：团队内存泄漏技能可命中、同名受管优先、缺源、路径逃逸拒绝、普通Python日志不误选嵌入式能力，以及正文变化后的hash回读。模板和规则检查不等于模型执行行为或产品验收。
